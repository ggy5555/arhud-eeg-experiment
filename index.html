같은 참가자의 보류 라운드에서 모델의 자기보고 예측 오차를 비교해요.

같은 세션 안에서 학습하지 않은 라운드를 평가합니다. 새 참가자·다른 날의 성능이나 EEG의 인과적 효과를 입증하지 않습니다.

05

다음 화면 선택 시연

선택한 블록 이전 자료로만 학습하여 이전 블록의 부담을 추정합니다.

7점은 테스트용 기준이며 의학적 경계가 아닙니다. 실제 평가 전 기준을 정해 두세요.

이 화면 선택은 작동 시연입니다. 예전에 측정한 결과를 바뀐 화면의 성과로 해석할 수 없으며, 실제 효과는 새 블록에서 별도 검증해야 합니다.

EXPERIMENT GUIDE

실험 전, 이렇게 준비해요.

같은 방식으로 진행할 수 있도록 기기와 화면을 먼저 점검해 주세요.

01

실험 준비

컴퓨터 화면과 MeasureWiz 착용 상태를 확인합니다. 장비 앱에서 EEG 녹화를 시작해 주세요. 화면의 설정은 파일럿 후보이며 본실험 전에 팀이 고정해야 합니다.

02

트리거 기록

각 블록의 시작과 종료 안내가 나오면 장비 앱에서 직접 트리거를 누르고 사이트에서 확인합니다. 클릭 시각은 기록되지만 앱에서 누른 정확한 시각과 같다고 보장하지 않습니다.

03

과제와 자기보고

산수식과 상태 질문의 정답을 F(O) 또는 J(X)로 응답합니다. 간결 화면에서 상태 질문이 나오면 스페이스바로 정보를 잠깐 열 수 있습니다. 매 블록 후 정신적 노력을 선택해 주세요.

04

저장과 분석

실험 기록과 MeasureWiz의 원본 CSV를 같은 익명 코드로 따로 저장합니다. 앱의 시간 열을 정렬하지 말고, 파일 순서와 녹화 공백 및 수동 트리거 오차를 파일럿에서 확인합니다.

i

일반 모니터의 AR-HUD 모사 실험입니다. 화면을 보다가 중단해도 되며, 실험 데이터는 공개 저장소에 올리지 마세요.
